# GitHub User Finder

## Автор
**Имя и Фамилия**: Казанцев Владислав

## Описание
GitHub User Finder — это GUI-приложение на Python с использованием Tkinter, которое позволяет:
- Искать пользователей GitHub по имени
- Просматривать результаты поиска
- Добавлять понравившихся пользователей в список избранного
- Сохранять избранных пользователей в JSON файл
- Управлять списком избранного (просмотр, удаление, очистка)
- Экспортировать избранное с временными метками

## Требования
- Python 3.7+
- tkinter (встроен в Python)
- requests

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/github-user-finder.git
cd github-user-finder
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование API

Приложение использует **GitHub Search API**:
- Endpoint: `https://api.github.com/search/users?q={username}`
- Лимит запросов: 60 запросов в час без аутентификации
- Для увеличения лимита используйте Personal Access Token

### Пример API запроса:
```bash
curl "https://api.github.com/search/users?q=octocat"
```

## Как использовать приложение

1. Запустите приложение:
```bash
python main.py
```

2. Введите имя пользователя GitHub в поле поиска
3. Нажмите "Поиск" или Enter
4. Выберите пользователя из результатов
5. Нажмите "Добавить в избранное" для сохранения
6. Используйте "Мои избранные" для просмотра сохраненных пользователей
7. Используйте "Экспортировать" для сохранения копии избранного

## Примеры использования

### Пример 1: Поиск пользователя
```
1. Введите "octocat" в поле поиска
2. Результат: octocat (ID: 1)
3. Нажмите "Добавить в избранное"
```

### Пример 2: Просмотр избранного
```
1. Нажмите "Мои избранные"
2. Откроется список всех добавленных пользователей с датой добавления
```

### Пример 3: Экспорт избранного
```
1. Нажмите "Экспортировать"
2. Создастся файл favorites_export_YYYYMMDD_HHMMSS.json
3. Файл содержит полную информацию всех избранных пользователей
```

### Пример 4: Удаление из избранного
```
1. Выберите пользователя из поиска или избранного
2. Нажмите "Удалить из избранного"
3. Пользователь будет удален из файла favorites.json
```
